Security model — defence in depth

Every request passes each layer in order. A failure at any layer stops it before it reaches patient data.

Transport & headersHTTPS · Helmet CSP (script-src 'self') · HSTS · frame protection · CORS allow-list · 1 MB body limit
Rate limitingGlobal 600/min · sign-in 20 per account and 500 per IP per 15 min (shared-NAT safe)
Authenticationbcrypt · 15-min JWT · rotating httpOnly refresh with replay detection · lockout after 5 failures
Tenant isolationtenant_id from the token only · every query scoped · other tenants' ids return 404 · suspended tenants blocked
Module licensingModules outside the plan rejected by the API (403), not just hidden
Permissions (RBAC)37 permissions · clinical writes reserved to clinicians · patients see only their own records
Validation & rulesZod on every input · server-computed totals · transactional locks
Audit trail — every sign-in and every change, with user, time and IP
